# Public reproduction notebook

`solana_sniper_reproduction.ipynb` reproduces the corrected development-only evidence used in the
Kaggle Writeup. It is designed to be public without redistributing competition data.

## Data access boundary

The notebook contains code and aggregate outputs only. It does not embed, upload, or publish raw or
processed competition rows. A participant must obtain the files through the official competition
channels and stage them under a private data root with this layout:

```text
<data-root>/
  raw/wallet/5brv79e_activity.parquet
  raw/june/pumpfun_trades.parquet
  processed/classification_dataset_creator_history.parquet
  processed/creator_history_manifest.json
  processed/entry_latency.parquet
  processed/replica_entry_prices.parquet
```

Set `SOLANA_SNIPER_DATA_ROOT` to `<data-root>` before running the notebook. When unset, the notebook
uses the repository's ignored `data/` directory. The entry-price audit JSON is generated by the
documented preprocessing workflow and must be present in `reports/generated/entry_prices_metrics.json`.

The notebook explicitly defines `t_decision` as token deployment and asserts that no final-holdout
prediction is generated. Post-deployment trades are loaded only in the backtest cells.

## Local execution

From the repository root:

```powershell
uv run --with jupyter --with nbconvert jupyter nbconvert `
  --to notebook --execute --inplace `
  --ExecutePreprocessor.timeout=1800 `
  notebooks/solana_sniper_reproduction.ipynb
```

The committed notebook is the executed version. Its SHA-256 and execution status are recorded in
`writeup/submission_manifest.json` before remote publication.
